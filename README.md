# Стамбул — Азисов Тамирлан

Каталог 72 мест Стамбула: еда, кофе, прогулки, книги, магазины и отели.

- `docs/index.html` — автономная опубликованная версия.
- `catalog/` — исходный код React/TypeScript.
- GitHub Pages: ветка `main`, папка `/docs`.

Поиск, категории и сохранённые места работают в браузере. Закладки хранятся только на устройстве читателя. Внешние ссылки ведут в Google Карты. Четыре точки с неуточнённым адресом отмечены в интерфейсе.

Данные собраны 7 ноября 2026 года. Общая подборка «Кофейни Стамбула» не включена. Личные заметки и частные ссылки не публикуются.

## Разработка

```sh
cd catalog
npm ci
npm run dev
```
